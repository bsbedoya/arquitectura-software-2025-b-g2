# Módulo 5: Ética de IA

## ¿Qué es la transparencia?

### Introducción

Un sistema de IA es **transparente** cuando se comparte información sobre:  

- Qué datos recopila  
- Cómo se usan y almacenan  
- Quién tiene acceso a ellos  

La transparencia es como **levantar el capó de un automóvil**: permite ver cómo funcionan juntas las distintas partes del sistema.  

---

### Objetivos del curso

Después de completar este módulo, debería ser capaz de:  

- Definir la transparencia.  
- Describir el gobierno de datos.  
- Identificar las funciones empresariales y los aspectos de la transparencia en los que intervienen.

### Identificar el problema

- La empresa bancaria busca automatizar el proceso de aprobación de hipotecas con IA.  

- Se ha desarrollado un **sistema de prueba de concepto**, evaluando:  
  
  - Imparcialidad del modelo  
  - Funciones de explicabilidad  
  - Solidez frente a ataques  
  - Privacidad de datos  

- Abi solicita detalles sobre:  
  
  - Fuentes de datos  
  - Transformaciones de datos  
  - Gestión de información personal  
  - Rendimiento del modelo y resultados de evaluaciones  

- Daniel detecta **inconsistencias en la documentación**, lo que hace difícil entender los detalles clave.  

> Necesidad: **Estandarizar la documentación y mejorar la transparencia**.  

---

### Explicar el problema

- Patricia propone un ejercicio para mapear los **detalles principales del sistema de IA** y quién puede proporcionarlos.  
- Se identifican dos grandes categorías:  

**Roles involucrados:**  

- Propietario de empresa  
- Diseñadores de IA  
- Ingenieros de datos  
- Jefe del modelo de IA  
- Científicos de datos  
- Validadores de modelos  
- Ingenieros de AIOps  
- Directores de riesgos  

**Datos del sistema:**  

- **Finalidad:** Propósito del sistema  

- **Política de datos y modelos:** Principios internos y normativas  

- **Aplicación y diseño:** Datos fuente, estadísticas, visualizaciones, transformación a características y objetivos  

- **Modelo:** Algoritmos, parámetros, rendimiento, pruebas de imparcialidad, explicabilidad, pruebas de solidez  

- **Despliegue:** Modelos desplegados, detalles de implementación, métricas bajo supervisión, umbrales, conformidad con normativas  

- El equipo correlaciona **roles y datos** para clarificar responsabilidades en cada fase: finalidad, diseño, datos, modelo y despliegue.  

- Se crea una **plantilla estandarizada** para registrar información en cada fase del proyecto.  

---

### Abordar el problema

- La transparencia permite que las preguntas sobre el sistema de IA sean **fáciles y rápidas de responder**.  
- El equipo implementa un plan para:  
  - Documentar qué datos se recopilan  
  - Cómo se utilizan  
  - Cómo se almacenan  
  - Quién tiene acceso  
- Esto contribuye a **crear un sistema de IA confiable y auditable**, mejorando la gobernanza y la confianza en la empresa.
