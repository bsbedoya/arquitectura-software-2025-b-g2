## 📌 Descripción del Proyecto

Este repositorio contiene el desarrollo del Proyecto Final para la asignatura **Arquitectura de Software**, correspondiente al periodo académico **2025B**.  
Incluye la estructura del backend, configuraciones, componentes y demás recursos necesarios para el funcionamiento del sistema.

---

## 📁 Estructura Principal del Repositorio

- `src/` – Código fuente del proyecto  
- `resources/` – Archivos de configuración  
- `pom.xml` – Dependencias y construcción del proyecto con Maven  
- `Dockerfile` – Construcción del contenedor Docker  
- `README.md` – Documentación del proyecto  

---

- **Maven**
- **Docker**

- **Trello** para gestión ágil
- **Arquitectura por capas**
